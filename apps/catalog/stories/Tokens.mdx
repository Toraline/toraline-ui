# Tokens

This page shows every design token of the library. The tables read the values from the package `@toraline.tech/tokens`, so they are always the current values.

## Words this page uses

- **Design token**: a named value of the design, for example a color or a font. It is stored as a CSS variable.
- **Level 1 token**: a raw value. The name says what the value is. Example: `--purple-500` is `#5e00a1`.
- **Level 2 token**: a meaning. The name says what the value is for. Example: `--color-primary` is the color of the main action. Components use only level 2 tokens.
- **Theme**: one set of values for the level 2 tokens. The library has the themes `light` and `dark`.

## How to read a table

Each row is one level 2 token. Each theme has one column. A cell shows, in this order:

1. A sample drawn with the value.
2. The level 1 token that the value points to, when there is one.
3. The raw value.

A cell always has the colors of its own theme. The control **Theme** in the toolbar changes the page around the tables, not the cells.
