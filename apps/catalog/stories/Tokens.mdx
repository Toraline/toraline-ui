# Tokens

This page shows every design token of the library. The tables read the values from the package `@toraline.tech/tokens`, so they are always the current values.

## Words this page uses

- **Design token**: a named value of the design, for example a color or a font. It is stored as a CSS variable.
- **Level 1 token**: a raw value. The name says what the value is. Example: `--color-brand-700` is `#42637c`.
- **Level 2 token**: a meaning. The name says what the value is for. Example: `--bg-primary` is the background of the main action. Components use only level 2 tokens.
- **Intraweb**: an app of Toraline. The default colors of the library are the colors of its design system, with the same names.
- **Theme**: one set of values for the level 2 tokens. The library has the themes `light` and `dark`.

## How to read a table

Each row is one level 2 token. Each theme has one column. A cell shows, in this order:

1. A sample drawn with the value.
2. The level 1 token that the value points to, when there is one.
3. The raw value.

A cell always has the colors of its own theme. The control **Theme** in the toolbar changes the page around the tables, not the cells.

## Colors

The first part of the name of a color token is its group. It says where the color is used: `--bg-*` a background, `--text-*` a text, `--border-*` a border, `--icon-*` an icon, `--data-*` a chart or a progress bar.

With the Tailwind preset each token is a class of its group only. `--bg-primary` is the class `bg-primary`, `--text-primary` is `text-primary`, `--border-default` is `border-default`, `--icon-default` is `text-icon`, and `--data-1` is `bg-data-1`, `text-data-1` and the classes of the other properties.
