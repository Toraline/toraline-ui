# Tokens

This page shows every design token of the library. The tables read the values from the package `@toraline.tech/tokens`, so they are always the current values.

## Words this page uses

- **Design token**: a named value of the design, for example a color or a font. It is stored as a CSS variable.
- **Level 1 token**: a raw value. The name says what the value is. Example: `--color-brand-700` is `#42637c`.
- **Level 2 token**: a meaning. The name says what the value is for. Example: `--bg-primary` is the background of the main action. Components use only level 2 tokens.
- **Intraweb**: an app of Toraline. The default colors of the library are the colors of its design system, with the same names.
- **Theme**: one set of values for the level 2 tokens. The library has the themes `light` and `dark`.

## How to read a table

Each row is one level 2 token. Each theme has one column. A cell shows, in this order:

1. A sample drawn with the value.
2. The level 1 token that the value points to, when there is one.
3. The raw value.

A cell always has the colors of its own theme. The control **Theme** in the toolbar changes the page around the tables, not the cells.

## Colors

The first part of the name of a color token is its group. It says where the color is used: `--bg-*` a background, `--text-*` a text, `--border-*` a border, `--icon-*` an icon, `--data-*` a chart or a progress bar.

With the Tailwind preset each token is a class of its group only. `--bg-primary` is the class `bg-primary`, `--text-primary` is `text-primary`, `--border-default` is `border-default`, `--icon-default` is `text-icon`, and `--data-1` is `bg-data-1`, `text-data-1` and the classes of the other properties.

## Fonts

The default fonts are Inter for normal text and Poppins for headings and buttons, the fonts of Intraweb. The library names the two fonts and downloads no font file: the app loads them. When the app loads no font, the browser uses a font of the device. The page **Guide** shows how an app loads the two fonts, and how it sets other fonts with the function `createTheme`.

## Spacing

`--spacing` is the spacing unit. A component writes every padding and gap as a multiple of it, for example `calc(var(--spacing) * 4)`. The bars of the sample are 1, 2, 4 and 8 units wide.

<Canvas of={TokenStories.Spacing} sourceState="none" />

## Radius

There are 4 radius sizes. With the Tailwind preset they are the classes `rounded-md` (a button, a field), `rounded-lg` (a menu, a popover), `rounded-xl` (a card, a table, a dialog) and `rounded-2xl` (a drawer).

## Shadows

There are 5 shadows. With the Tailwind preset they are the classes `shadow-sm`, `shadow-card` (a card, a table), `shadow-lg` (a menu, a popover), `shadow-xl` and `shadow-2xl` (a dialog, a drawer). The two themes of the library have the same shadows. A theme of an app can change them.

<Canvas of={TokenStories.Shadows} sourceState="none" />

## Text styles

A text style is one class of the Tailwind preset that sets the font, the size, the line height and the weight of a text together. Example: `<h1 className="heading-page">`. The sizes are in `rem`, a length that follows the font size of the page (`1rem` is 16 pixels when the person did not change it). A text style is the same in every theme; its font is the token `--font-heading`.

# Tokens

Esta página mostra todos os design tokens da biblioteca. As tabelas leem os valores do pacote `@toraline.tech/tokens`, então eles são sempre os valores atuais.

## Palavras que esta página usa

- **Design token**: um valor do design que tem nome, por exemplo uma cor ou uma fonte. Ele é guardado como uma variável CSS.
- **Token de nível 1**: um valor bruto. O nome diz o que o valor é. Exemplo: `--color-brand-700` é `#42637c`.
- **Token de nível 2**: um significado. O nome diz para que o valor serve. Exemplo: `--bg-primary` é o fundo da ação principal. Os componentes usam só tokens de nível 2.
- **Intraweb**: um app da Toraline. As cores padrão da biblioteca são as cores do design system dele, com os mesmos nomes.
- **Tema**: um conjunto de valores para os tokens de nível 2. A biblioteca tem os temas `light` e `dark`.

## Como ler uma tabela

Cada linha é um token de nível 2. Cada tema tem uma coluna. Uma célula mostra, nesta ordem:

1. Uma amostra desenhada com o valor.
2. O token de nível 1 para o qual o valor aponta, quando existe um.
3. O valor bruto.

Uma célula sempre tem as cores do seu próprio tema. O controle **Theme** na barra de ferramentas muda a página em volta das tabelas, não as células.

## Cores

A primeira parte do nome de um token de cor é o grupo dele. Ela diz onde a cor é usada: `--bg-*` um fundo, `--text-*` um texto, `--border-*` uma borda, `--icon-*` um ícone, `--data-*` um gráfico ou uma barra de progresso.

Com o preset do Tailwind cada token é uma classe só do grupo dele. `--bg-primary` é a classe `bg-primary`, `--text-primary` é `text-primary`, `--border-default` é `border-default`, `--icon-default` é `text-icon`, e `--data-1` é `bg-data-1`, `text-data-1` e as classes das outras propriedades.

`--spacing` é a unidade de espaçamento. Um componente escreve todo padding e todo gap como um múltiplo dela, por exemplo `calc(var(--spacing) * 4)`. As barras da amostra têm 1, 2, 4 e 8 unidades de largura.

## Estilos de texto

Um estilo de texto é uma classe do preset do Tailwind que define a fonte, o tamanho, a altura da linha e o peso de um texto juntos. Exemplo: `<h1 className="heading-page">`. Os tamanhos estão em `rem`, um comprimento que acompanha o tamanho de fonte da página (`1rem` são 16 pixels quando a pessoa não mudou esse tamanho). Um estilo de texto é o mesmo em todo tema; a fonte dele é o token `--font-heading`.
